Sum of Even Numbers

Easy

You are given a number N followed by N integers. Print the sum of all even numbers among them.

Input Description:
First line contains N. Second line contains N space separated integers.

Output Description:
Print a single integer, the sum of even values.

Constraints:
1 <= N <= 100000

Sample Input :
5
1 2 3 4 5

Sample Output :
6
